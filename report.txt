I have been working on the trading the liquidity management bot. The last update I sent has 2 projects, one for trading and the other for bridging BTC to TBTC. I have merge the project to together as a single system where diverse rules (strategies) can be created.
I have implemented strategy that can be configured for
1. bridging specific amount of BTC to TBTC at a set interval
```json
{
  "strategies": [
    {
      "name": "BTC Bridge",
      "key": "btcb",
      "type": "btc-bridge",
      "privateKeyEnvKey": "TBTC_PRIVATE_KEY",
      "amount": "0.2",
      "interval": 86400,
      "btcFeeRate": 70
    }
  ]
}
```
This strategy will:
- Bridge 0.2 BTC every 24 hours
- Use a fee rate of 70 sats/vB

2. sell/buying of BTC (or any coin) on uniswap
```json
{
  "strategies": [
    {
      "name": "USDC-ETH DCA",
      "key": "dca_usdc_eth",
      "type": "dca",
      "privateKeyEnvKey": "STRATEGY_1_KEY",
      "base_token": "USDC",
      "quote_token": "ETH",
      "interval": 3600,
      "amount": "100",
      "slippage": 0.5
    }
  ]
}
```
This strategy will:
- Buy ETH with USDC
- Spend 100 USDC per trade
- Execute every hour (3600 seconds)
- Allow 0.5% slippage

3. liquidity provision on uniswap
```json
{
  "strategies": [
    {
      "name": "ETH-USDC LP",
      "key": "lp_eth_usdc",
      "type": "lp",
      "privateKeyEnvKey": "STRATEGY_1_KEY",
      "base_token": "ETH",
      "quote_token": "USDC",
      "interval": 60,
      "token0": "0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2",
      "token1": "0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48",
      "token0Symbol": "WETH",
      "token1Symbol": "USDC",
      "token0Name": "Wrapped Ether",
      "token1Name": "USD Coin",
      "chainId": 1,
      "fee": 3000,
      "priceRange": {
        "lowerBoundPercent": -10,
        "upperBoundPercent": 10
      },
      "totalValueInToken0": "5",
      "autoCompound": {
        "enabled": true,
        "threshold": 0.01,
        "maxGasFee": "50",
        "interval": 3600,
        "minFeesForCompound": "10"
      },
      "rebalance": {
        "enabled": true,
        "threshold": 5
      }
    }
  ]
}
```
This strategy will:
- Provide liquidity for ETH/USDC pair
- Set price range ±10% around current price
- Initially deposit an x amount of ETH and y amount of USDC in the pool such that initial liquidity is 5 ETH
- Auto-compound rewards hourly if above $10
- Rebalance position if price moves more than 5%
